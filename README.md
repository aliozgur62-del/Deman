# Borsa İstanbul Anadolu Lisesi · Ders Paneli

Lise 9, 10 ve 11. sınıf öğrencileri için ders paneli ve birebir ders sayfası.
Öğretmen konuları seçer, öğrenci panelinde ve birebir sayfasında görür.

## Çalıştırma
`index.html` dosyasını tarayıcıda açmanız yeterlidir. Derleme gerekmez.

## GitHub Pages ile yayınlama
Settings → Pages → Branch: `main` / `(root)` → Save

## Not
Veriler şu an tarayıcıda (localStorage) saklanır. Cihazlar arası paylaşım için Firebase veya Supabase eklenebilir.
